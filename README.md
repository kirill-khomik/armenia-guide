# Армения без гонки

Одностраничный личный путеводитель по Армении. Проект намеренно сделан без
фреймворков, сборки и зависимостей: только HTML, CSS и небольшой JavaScript.

Сайт публикуется через GitHub Pages из корня ветки `main`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой простой статический сервер.
