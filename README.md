# Армения без гонки

Одностраничный личный дневник об Армении для друзей. Проект намеренно сделан
без фреймворков, сборки и зависимостей: только HTML и CSS.

Сайт публикуется через GitHub Pages из корня ветки `main`.

## Локальный просмотр

Откройте `index.html` в браузере или запустите любой простой статический сервер.
